# Regression Tests

Bugs that were found and fixed. Each entry becomes a permanent regression test to prevent recurrence.

## How to Use
- Every bug fix gets an entry here
- Include the root cause so future developers understand the risk area
- Link to the original test case or requirement if applicable

| REG-001 | `CUSTOMER_FEEDBACK.SUBCATEGORY` was `NUMBER(38,0)` and rejected daily-increment string writes for the entire 2025-2026 season | `write_pandas(auto_create_table=True)` infers types from the first sample.
