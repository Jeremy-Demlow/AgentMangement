# Data Dictionary

All data objects used in this project. Keep this updated as tables, views, and models are created.

> **Note:** `{DATABASE}` refers to the environment-specific database: `AM_SKI_RESORT_DEV`, `AM_SKI_RESORT_QA`, or `AM_SKI_RESORT_PROD`.

## Raw Tables ({DATABASE}.RAW)

Generated by `data_generation/` — 21 tables spanning 5 ski seasons (Nov 2020 - present).

## Column Reference

Key columns shared across multiple objects:

| Column Name | Data Type | Definition | Valid Values | Source |
|-------------|-----------|------------|--------------|--------|
| DATE_KEY | NUMBER | Surrogate key for date dimension | Integer | DIM_DATE |
| FULL_DATE | DATE | Calendar date | 2020-11-01 to present | DIM_DATE |
| SKI_SEASON | VARCHAR | Ski season identifier | '2020-2021' through '2025-2026' | DIM_DATE |
| CUSTOMER_KEY | VARCHAR | Surrogate key for customer dimension | UUID | DIM_CUSTOMER |
| CUSTOMER_SEGMENT | VARCHAR | Customer value segment | 'premium', 'regular', 'budget', 'group' | DIM_CUSTOMER |
| IS_PASS_HOLDER | BOOLEAN | Whether customer holds a season pass | TRUE/FALSE | DIM_CUSTOMER |
| PURCHASE_AMOUNT | NUMBER | Transaction amount in USD | > 0 | FACT_TICKET_SALES, FACT_RENTALS |
| PURCHASE_CHANNEL | VARCHAR | How the ticket was purchased | 'online', 'window', 'mobile', 'partner' | FACT_TICKET_SALES |
