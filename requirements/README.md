# Requirements

This folder contains one file per feature or epic. Use the template below for new requirements.

## How to Use
1. Copy `_TEMPLATE_requirement.md` and rename it (e.g., `REQ-001_user_auth.md`)
2. Fill in all sections
3. Link test cases in `tests/test_cases.md` to the requirement ID
4. Update `user_stories.md` with the associated stories

## Naming Convention
`REQ-[NNN]_[short_description].md`
