OVERALL ARCHITECTURE — library-first, versioning-aware
========================================================

  +-------------------------------------------------------------+
  |                     AgentMangement REPO                     |
  |                                                             |
  |  agents/specs/*.yml           <-- source of truth (spec)    |
  |  semantic-views/              <-- SV YAML + VQRs            |
  |  dbt_ski_resort/              <-- dbt project (tables, SV)  |
  |  environments/*.env.yml       <-- env config + deploy_alias |
  |  project.yml                  <-- agent_versioning flag     |
  |                                                             |
  |  agent_management/            <-- THE LIBRARY               |
  |    deploy_agents.py    rollback.py       versioning.py      |
  |    snapshot_state.py   smoke_test.py     snapshot_agent.py  |
  |    validate_spec_format.py      detect_sv_drift.py          |
  |    run_ci_eval.py               deploy_semantic_views.py    |
  |                                                             |
  |  tests/                       <-- unit + integration tests  |
  |  reqs/                        <-- THIS folder (design)      |
  |  docs/operations/             <-- runbooks                  |
  +-------------------------------------------------------------+
          |                                      |
          | (PR merges)                          | (python -m …)
          v                                      v
